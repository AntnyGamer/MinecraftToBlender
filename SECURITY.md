# Security Policy

## Supported versions

Security fixes are maintained for the current v1 code on `main`.
Older copies and experimental builds are not supported.

## Reporting a vulnerability

Please **do not** post security-sensitive details, credentials, private Minecraft saves, or proof-of-concept exploits in a public GitHub issue.

Use [private vulnerability reporting](https://github.com/AntnyGamer/MinecraftToBlender/security/advisories/new) if the repository owner has enabled it. If that option is unavailable, contact the repository owner privately using a contact method from their GitHub profile before disclosing details.

Include a concise description, affected version/commit, reproducible steps, and the impact. Remove any world data, secrets, and personal paths from logs before sharing.

There is no guaranteed response-time or security-bounty commitment.
